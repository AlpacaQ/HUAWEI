# 同一个图片包的交接接口

朱雨萱、石韵涵必须使用同一个 `inspection_image_delivery_v2_5images.zip` 包及其中已经编码的文件。解压入口为 `delivery_v2/package_index.json`。接收者解压后读取，不重新缩放、压缩或另存JPEG。

本版包含5张独立真实照片，每张17个传输JPEG，合计85个；另有5个source/original.jpg，所以递归搜索整个包会找到90个JPEG。只统计各payload目录内的85个JPEG。首张17个JPEG逐字节沿用首包。

| 图片ID | 正确答案记录 | 确认状态 |
|---|---|---|
| meter01 | 3.23 V（直流） | 用户已确认 |
| meter02 | null（无法确认） | 用户标记无法确认 |
| meter03 | 温度22.9 °C；相对湿度40% | Codex视觉核对，用户未标记修改；未冒充人工确认 |
| meter04 | null（无法确认） | 用户标记无法确认 |
| meter05 | 主读数0.385 V；辅助显示000.0（单位未知） | Codex视觉核对，用户未标记修改；未冒充人工确认 |

meter02、meter04可用于传输与ROI流程测试，**不能作为有正确读数标签的准确率样本**。每张ground_truth.json中保留来源、许可、ROI和人工确认状态。若只使用人工确认的准确率标签，目前仅meter01符合；meter03、meter05需人工复核后用于这一口径。被排除的两张无可辨认读数候选记录于excluded_candidates.json。

## 目录与路径

`package_index.json` 是全包入口，images 内 manifest、source_file、roi_preview 均相对于包根目录。每张图的 `meterXX/payload/manifest.json` 对应一个独立传输集。

manifest 的 payload 相对于该 manifest 所在目录解析，禁止相对于仓库根目录或当前工作目录解析。每集恰好17个JPEG：`thumbnail.jpg`、`tile_00.jpg`至`tile_15.jpg`。原图存于 source，PNG预览存于 review，均为辅助资料，不加入17个传输JPEG的统计。

## 坐标和重点

EXIF朝向校正后转RGB，坐标基于这一完整尺寸。原点在左上，x向右、y向下，单位为整数像素。ROI和box采用 `[x0,y0,x1,y1]`，左上包含、右下不包含。宽高为x1-x0、y1-y0；最后可见像素为(x1-1,y1-1)。ROI框住整个LCD显示区域；单位若未显示在LCD中，正确答案记录必须写明档位等证据。

固定4×4，tile_id从0到15：第一行0、1、2、3，第二行4、5、6、7，第三行8、9、10、11，第四行12、13、14、15。边界为 `i*width//4` 和 `i*height//4`（i=0..4），覆盖所有像素。

**priority=1是重点，priority=0是背景。** 与ROI有正面积交集即为重点，仅接触边缘不算。priority不是序号，不能升序排序来表达重点优先。重点队列先缩略图，再按 `(-priority,tile_id)` 排块；普通队列先缩略图，再按tile_id升序。两个队列复用完全相同的文件。

## 字节与身份校验

size_bytes为已经落盘文件的真实字节数；total_size_bytes只等于缩略图和16块之和，不含原图、预览、JSON、ZIP或协议开销。图块quality=80；缩略图最长边≤256、quality=50。接收端直接读取文件二进制作为传输内容。

package_index还保存每个传输文件及原图的SHA256，便于两人核对拿到同一版本。答案与来源保存在每张图的ground_truth.json。未经过真实人工确认不得标为已确认；读不清的答案设为null并记录原因。

## 运行位置

在FPGA仓库根目录先执行 `Set-Location inspection_image`。下面的命令都在inspection_image目录运行：

```powershell
python verify_package.py delivery_v2
```

验收脚本只读取，不编码JPEG。也可以使用Python可执行文件的完整路径。收到包无需执行image_processing.py。仅下载ZIP的同学在解压目录运行：

```powershell
Set-Location delivery_v2
python verify_package.py .
```

包内已附verify_package.py、image_processing.py和requirements.txt。Python 3.10以上且安装Pillow即可验收；缺少依赖时在此目录执行 `python -m pip install -r requirements.txt`。JPEG已经生成，使用图片包本身无需安装Python。

## 交接记录

软件核验通过表示包可以交接，不代表两位接收者已实际收到。实际交接需记录两人收到的ZIP SHA256及各自验收结果。用户本轮明确要求扩展为5张，本版按此授权扩展；接收者收包状态仍为pending。所有照片均为公开来源真实照片，不代表本队自行采集的现场数据。
